Section 1: Logic Gates Resistance Analysis

Q: Calculate the ratio of the best-case rising resistance to the worst-case falling resistance for a CMOS 2-input NAND Gate (assuming equal lengths and widths).

Answer: The ratio is 1/2.

  • Best-case Rising (Pull-Up Network): Both PMOS transistors are ON in parallel.
    $R_{rise\_best} = R_P \parallel R_P = R_P / 2$
  • Worst-case Falling (Pull-Down Network): Both NMOS transistors are in series and must be ON for the output to fall.
    $R_{fall\_worst} = R_N + R_N = 2R_N$

Assuming typical mobility where electron mobility is roughly twice hole mobility ($\mu_n \approx 2\mu_p$), and given equally sized transistors ($W_N = W_P$), we establish that $R_P = 2R_N$.

$$Ratio = \frac{R_{rise\_best}}{R_{fall\_worst}} = \frac{R_P / 2}{2R_N} = \frac{2R_N / 2}{2R_N} = \frac{R_N}{2R_N} = \frac{1}{2}$$

Q: Is there any difference between best-case and worst-case falling resistance in a 2-input NAND gate?

Answer: No, there is no difference.

The falling transition is controlled by the Pull-Down Network (PDN), which consists of two NMOS transistors connected in series. For the output to fall to ground, both inputs must be High to turn on both NMOS transistors. Because there is only one possible input combination that creates a complete path to ground, there is only one possible resistance value: $R_{fall} = R_N + R_N = 2R_N$.

Q: Calculate the ratio of best-case rising to worst-case falling resistance for a 2-input NOR gate.

Answer: The ratio is 4.

  • Best-case Rising (PMOS in Series): $R_{rise\_best} = 2R_P$
  • Worst-case Falling (NMOS in Parallel): Occurs when only one NMOS is ON. $R_{fall\_worst} = R_N$

Substituting $R_P = 2R_N$:

$$Ratio = \frac{2R_P}{R_N} = \frac{2(2R_N)}{R_N} = \frac{4R_N}{R_N} = 4$$

Q: What is the ratio of best-case rising resistance to BEST-case falling resistance for a 2-input NOR gate?

Answer: The ratio is 8.

The best-case falling resistance occurs when both parallel NMOS transistors are ON simultaneously.

  • Best-case Rising: $R_{rise\_best} = 2R_P$
  • Best-case Falling: $R_{fall\_best} = R_N \parallel R_N = \frac{R_N}{2}$

Substituting $R_P = 2R_N$:

$$Ratio = \frac{2R_P}{R_N / 2} = \frac{4R_N}{0.5R_N} = 8$$

Section 2: Timing & Clock Skew

Q: Write setup and hold time equations for two flip-flops with a combinational delay. Explain the impact of positive and negative clock skew ($\delta$).

Ideal Clock Equations
  • Setup Time: $t_{cq} + t_{comb(max)} \le T_{clk} - t_{su}$
  • Hold Time: $t_{cq} + t_{comb(min)} \ge t_{h}$
Equations with Delay $\delta$ in Capture Path (Positive Skew)
  • Setup Time: $t_{cq} + t_{comb(max)} \le T_{clk} + \delta - t_{su}$
  • Hold Time: $t_{cq} + t_{comb(min)} \ge t_{h} + \delta$
Impact Analysis
Positive Skew:
  • Setup Time: Decreases chances of violations (more time for data to arrive).
  • Hold Time: Increases chances of violations (data must be held longer).
Negative Skew:
  • Setup Time: Increases chances of violations (less time for data to arrive).
  • Hold Time: Decreases chances of violations (data hold requirement is reduced).

Section 3: Current Mirrors

Q: Draw and explain NMOS and PMOS Current Mirrors. Why is NMOS generally preferred?

1. Why NMOS is Often Preferred (The Mobility Advantage)

NMOS is often favored due to Carrier Mobility. Electrons have a much higher mobility ($\mu_n \approx 2\mu_p$ to $3\mu_p$) than holes. Therefore, an NMOS transistor can be physically smaller than a PMOS to drive the same current, saving silicon area and reducing parasitic capacitances (making NMOS mirrors faster).

2. NMOS Current Mirror (Current Sinking)

3. PMOS Current Mirror (Current Sourcing)
       V_DD                       V_DD
         |                          |
       S |                        S |
       +---+                      +---+
     G |   |                    G |   |
  +----+-+ |                      | +-+----+

Operation Principle: M1 is diode-connected (Gate shorted to Drain), operating in saturation. $I_{REF}$ forces M1 to develop a specific gate-source voltage. Because M2 shares this exact gate-source voltage and is identical to M1, it naturally mirrors (duplicates) $I_{REF}$ into the load as $I_{OUT}$.

Section 4: Device Physics & Body Effect

Q: Why is the body terminal connected to the source in CMOS? What happens if it's connected to the drain?

Why Body is connected to Source:

  1. Eliminate Body Effect: Keeps $V_{SB} = 0$, ensuring a stable threshold voltage ($V_{TH}$).
  2. Prevent Latch-up: Keeps the parasitic body-to-source and body-to-drain PN junction diodes strictly reverse-biased.
What if Body is connected to Drain? (SHORT CIRCUIT)
Connecting the Body (P-type in NMOS) to the Drain (tied to $V_{DD}$) forces the substrate to a high voltage. This strongly forward-biases the internal Body-to-Source parasitic diode. A massive, unrestricted current bypasses the channel entirely, flowing straight from $V_{DD}$, through the substrate, into Ground, destroying the chip via latch-up.

Q: Why is the NMOS substrate 'p' instead of 'p+'? What changes if 'p+' is used?

The substrate is lightly doped (p-) to allow a manageable gate voltage to invert the channel. If a heavily doped (p+) substrate were used, the following catastrophic changes would occur:

  • Threshold Voltage Skyrockets: It becomes incredibly difficult to repel the massive concentration of holes. $V_{TH}$ would become too high for standard logic operations.
  • Mobility Degrades: Massive ionized impurity scattering would severely lower electron mobility ($\mu_n$), slowing down the transistor.
  • Junction Capacitance Increases: The n+/p+ junction creates a microscopic depletion width, acting as a high-value capacitor causing tremendous RC delays.
  • Breakdown Voltage Plummets: The strong electric field across the narrow depletion region would cause Zener breakdown at low voltages.
  • Exaggerated Body Effect: The body effect parameter ($\gamma$) is directly proportional to $\sqrt{N_A}$, making threshold voltages highly unstable.

Q: Why are the Source and Drain n+ instead of n?

  • Ohmic Contacts: Heavy doping (n+) thins the barrier at the metal-silicon junction enough to allow quantum tunneling. This prevents a rectifying Schottky diode from forming, ensuring current can flow freely in both directions.
  • Reduced Series Resistance: It acts as a highly conductive path, ensuring voltage reaches the channel without being wasted as heat.
  • Carrier Reservoir: Provides a massive supply of free electrons to flood the channel instantly when the transistor turns ON.

Section 5: Buffers & Transmission Gates

Q: What happens if you exchange PMOS & NMOS in a CMOS inverter?

This circuit is called a Poor Buffer or Degraded Buffer. It stops inverting and attempts to follow the input, but with severely degraded logic levels.

  • Logic High (NMOS Pulling Up): Maxes out at a "Weak 1" ($V_{DD} - V_{THN}$) because the NMOS pinches off.
  • Logic Low (PMOS Pulling Down): Bottoms out at a "Weak 0" ($|V_{THP}|$) because the PMOS pinches off.

Q: How do you construct a rail-to-rail buffer? Can a Transmission Gate be used instead?

1. Cascaded Inverters (Rail-to-Rail Buffer)

A true rail-to-rail buffer is built by cascading two standard CMOS inverters in series. It actively regenerates the signal and isolated loads.

          V_DD                       V_DD
           |                          |
         +-+-+                      +-+-+
         |   |                      |   |
       G |   |                    G |   |
 V_in ---+-+ |              +-------+-+ |
           | | PMOS1        |         | | PMOS2
           +-+              |         +-+
         D |                |       D |
           +---- Node X ----+         +---- V_out
         D |                |       D |
           +-+              |         +-+
       G   | | NMOS1        |     G   | | NMOS2
      ---+-+ |              +-------+-+ |
         |   |                        | |
         +-+-+                      +-+-+
           |                          |
          GND                        GND
2. Drawbacks of a Transmission Gate as a Buffer

While a transmission gate passes full rail-to-rail voltage, cascaded inverters are strongly preferred. A permanently ON transmission gate has severe drawbacks:

  • No Signal Regeneration: It is a passive element. It simply passes noisy or degraded inputs directly to the output without reshaping them into sharp square waves.
  • Zero Load Isolation: The input driving circuit directly "sees" whatever heavy capacitive load is on the output, causing massive delays.
  • Added RC Delay: It introduces series resistance ($R_{on}$), creating an RC low-pass filter with the load capacitance.
  • Wasted Area: If purely passive connection is needed, a metal wire is superior and consumes no active silicon area.
